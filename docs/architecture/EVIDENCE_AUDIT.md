# Evidence and Audit Contract

## Objective

Every important architecture decision should be explainable from evidence.

## Evidence Categories

- Device identity
- Platform
- Model
- OS version
- Firmware version
- Capabilities
- Authorization state
- Service state
- Policy result
- Entitlement result
- Final decision

## Audit Principle

Evidence is descriptive.

Evidence must not be used to fabricate authorization or entitlement.

## Validation

Automated validation is deferred until the final project gate.
