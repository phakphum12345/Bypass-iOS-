# Bypass-iOS — Phase 9 Release Contract

## Release Requirements

Before release:

1. Flutter source must format cleanly.
2. Static analysis must pass.
3. Unit tests must pass.
4. Widget tests must pass.
5. Web release build must pass.
6. Linux release build must pass.
7. Documentation must exist.
8. Security boundaries must be represented.
9. Git working tree must be intentionally controlled.
10. Local and remote main must synchronize.

## Documentation

Canonical architecture documentation must be generated and verified
without unexpected drift.

## Security

Release validation must preserve the defensive security boundary.

## Final Gate

All release requirements must pass before merge to main.
